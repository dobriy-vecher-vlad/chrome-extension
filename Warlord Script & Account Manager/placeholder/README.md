# Warlord Script: заглушка

Замена старого расширения «Warlord Script» в Chrome Web Store. Вместо характеристик игрока на странице профиля `vk.ru`
(и `vk.com`) показывает такой же по виду блок с макетом из заглушек и кнопкой «Обновить расширение», которая ведёт на
[Warlord Script & Account Manager](https://chromewebstore.google.com/detail/warlord-script-account-ma/bjacddoljhbhgagfhbdacckecocnkilo).
Без заголовка, версии, настроек и выбора сервера, без сети и без хранилища.

Если на странице уже есть блок нового расширения (`#warlord-script-host`), заглушка не показывается.

## Сборка

```
cd placeholder
npm run build
```

Зависимости (esbuild, React, VKUI) берутся из `node_modules` основного проекта. Результат: папка `build/` (содержимое расширения) и
архив `build/build.zip` для публикации. Папка `build/` генерируется целиком и не хранится в репозитории.

## Устройство

- `public/manifest.json` — манифест (один content script `content.js`, права на `vk.ru` и `vk.com` только через `matches`);
- `src/main.jsx` — вставка блока первым в колонку профиля и слежение за страницей (ВК — SPA);
- `src/Block.jsx` — сам блок (VKUI, тема и цвета берутся у страницы ВК);
- `src/pageStyles.js`, `src/styles.css` — таблица стилей для Shadow DOM;
- `scripts/build.mjs` — сборка, чистка стилей VKUI от неиспользуемых классов, архив.

## Публикация

Версия в манифесте должна быть выше опубликованной у старого расширения (там 3.0.4). Новый хост `vk.ru` у старого расширения
может не быть среди разрешений: если его не было, Chrome отключит расширение у пользователей после обновления, пока они
не подтвердят новое разрешение.
