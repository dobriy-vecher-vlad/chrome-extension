# Warlord Account Manager

Расширение для Chrome: переключение между аккаунтами в игре Warlord (ВКонтакте, `vk.ru`).

Интерфейс собран на React и VKUI и живёт в Shadow DOM, поэтому стили страницы ВК ему не мешают.

Импорт и экспорт аккаунтов — текстовый файл, по строке `Название,ключ,номер` (тот же формат, что `game_users` старого Warlord Script).
Если на странице есть панель старого расширения, аккаунты из неё переносятся автоматически, а сама панель скрывается (`src/page.css`).

Настройки (окно «Настройки» в панели): аккаунты, хранилище (импорт, экспорт, очистка, занятое место), оформление (скрыть рекламный блок, исправить `--layout-width`, свободный режим панели) и справка. Значения оформления хранятся под ключом `settings` в `chrome.storage.local`.

## Сборка

```bash
npm install
npm run build      # собирает build/ целиком и кладёт в неё build.zip для публикации (манифест в корне архива)
npm run watch      # пересборка при изменениях (и src/, и public/)
```

Папка `build` генерируется (в git не хранится) и содержит готовое расширение: `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное расширение».

## Структура

- `src/` — исходники интерфейса (`content.jsx` — точка входа, `App.jsx`, `components/`, `hooks/`, `lib/`). `page.css` — правки страницы ВК (высота фрейма игры, скрытие панели старого расширения): вшивается в `content.js` и подключается только пока панель на странице
- `public/` — статичные файлы расширения, копируются в `build/` как есть: `manifest.json`, `background.js` (сетевые запросы), `game-frame.js` (скрывает рекламный блок внутри самого фрейма игры), `icons/`. Манифест и эти файлы правятся здесь
- `build/` — результат сборки (`public/` + собранный `content.js`), его не редактируют
- `test-data/` — файл `warlord-accounts-test.txt` с вымышленными аккаунтами для проверки длинного списка (Настройки → Хранилище → Импортировать из файла). Ключи в нём случайные, игра их не примет
